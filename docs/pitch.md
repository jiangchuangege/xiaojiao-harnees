## 摘要

本文用一页篇幅说明小焦是什么、能做什么、技术实现落在哪里、适合谁使用，以及当前的局限。
所有能力条目都能在仓库中找到对应代码，未落地的部分在文末单独列出。

## 1. 项目定位

小焦是一个**本地优先**的 AI 系统。它把大模型当作可替换的零件，在模型外面维护记忆、工具、
人格配置与会话状态。换模型不需要改代码、不需要重建记忆；模型服务不可用时，系统仍可运行，
只是能力范围缩小。

设计取向是"载体优先"：能力由载体层实现，模型只负责当前这一步的推理。
这使小焦可以在小参数量模型上完成需要长上下文、多工具与多次请求的组合任务。

## 2. 能力清单

| 能力 | 说明 |
|---|---|
| 对话 | 网页端聊天，会话持久化，支持多轮与长文续写 |
| 记忆 | 历史对话写入外部向量库，每轮按相似度检索后注入提示词，不占模型上下文窗口 |
| 联网检索 | 内置抓取与搜索插件，带同域限速、会话回收与熔断 |
| 工具执行 | 建文件、写网页、跑命令、读写文件等。默认对危险命令先回显原文并要求确认，确认后才执行 |
| 多大脑调度 | 聊天、编码、视频、播客与云端视频各自注册为独立大脑，任一时刻只有一颗占用显存 |
| 文生视频 | 本地链路用 ComfyUI 加 Wan2.1 做扩散生成，也可切换到云端视频接口 |
| 播客生成 | 写稿、配音、拼接、封面四步出成品音频 |
| 音乐生成 | 本地 MusicGen，按文字描述生成短音频 |
| 预设切换 | 人格、大脑、工具开关与采样参数打包成一个预设，选中即生效，不重启 |
| 插件生态 | 支持 Python、JSON、Markdown、JavaScript 四类插件，放入目录即注册 |
| 外部接入 | 暴露 OpenAI 兼容接口，可被任意兼容客户端当作模型提供方接入 |
| 成本看板 | 统计调用次数、Token 用量、花费与节省 |
| 可选的桌面形象 | 接入独立的 N.E.K.O. 桌面客户端，并提供一条读取其记忆的学习通道 |

## 3. 为什么需要它

市面上的 AI 助手多数是"打开网页才能用"的工具，使用者的记忆、文件与操作习惯留在各个网页里。
小焦要解决的是**把 AI 放进用户自己的机器**：模型、记忆、会话与产物都在本机，
数据不出本机；工具能直接操作本机文件与命令；能力可以按需扩展，而不是等产品方排期。

由此得到三类适用场景：

| 用户 | 关注点 | 对应能力 |
|---|---|---|
| 普通使用者 | 装好即用，不需要配环境 | 一键启动脚本、依赖自检、网页界面 |
| 开发者 | 换模型不改代码，扩展能力不改主程序 | 模型可插拔、插件即目录、OpenAI 兼容接口 |
| 关注隐私与数据自主的使用者 | 数据不出本机，可完全离线 | 本地模型、本地向量库、本地生成链路 |

## 4. 技术实现

| 组成 | 实现 | 代码位置 |
|---|---|---|
| 载体层 | 记忆、工具、世界配置、会话的集中管理 | `core/` |
| 模型层 | 火种登记处，登记、探测与兜底当前模型端点 | `core/carrier/brain_registry.py` |
| 多大脑调度 | 大脑注册表、显存让位与温存策略 | `brain_manager.py`、`video_service/model_switch.py` |
| 对话主循环 | 提示词组装、工具调度、记忆检索、长文续写 | `xiaojiao_app.py` |
| 视频 | ComfyUI 加 Wan2.1，或云端视频接口 | `video_service/` |
| 播客 | 写稿、Chatterbox 配音、pydub 拼接、SD1.5 封面 | `podcast_service/` |
| 音乐 | 本地 MusicGen | `plugins/music_generation.py` |
| 插件桥 | 识别 OpenAI、Claude、DSH 三种工具清单并转成小焦插件 | `xiaojiao_app.py` 的 `_make_tools_plugin()` |
| 小脑 | 自研 MiniGPT，做轻量判断与离线兜底 | `xiaojiao_harness.py` |

需要澄清一处容易夸大的说法：多大脑的"秒级切换"有明确前提。同一个 llama-swap 进程内的模型
之间切换（聊天与编码）是权重的卸载与加载，属秒级；跨服务切换（例如从聊天切到视频）
还包含一次进程启动或状态恢复，耗时以秒到分钟计。详见 [brain-switch.md](brain-switch.md) 第 7 节。

## 5. 运行方式

```powershell
cd xiaojiao-harness
pip install -r requirements.txt
python start_xiaojiao.py
```

启动脚本会依次拉起 llama-swap（9292）与网页服务（5000），并询问是否同时启动可选的
N.E.K.O. 桌面客户端。随后打开 `http://127.0.0.1:5000` 即可使用。

必需项只有两类：Python 解释器与依赖包，以及小脑三件套。其余组件缺失时按项降级，
安装器会明确列出缺什么、影响哪个功能，不写死任何本地路径。

## 6. 已知局限

1. **硬件规格不做承诺**。本文档不给出显存或内存的绝对要求，实际是否可运行取决于所选模型、
   量化精度、分辨率与帧数，请以本机实测为准。
2. **"本地优先"不等于"只能本地"**。默认链路全部本地，但接入云端模型或云端视频接口后，
   相关请求会离开本机。
3. **音乐能力与调度是两套机制**。音乐由插件直接管理显存，未注册进大脑注册表，
   因此不会出现在 `/monitor` 的大脑清单里。
4. **图像与推理大脑尚未落地**。注册表里只有注释形式的预留位置。
5. **ACE-Step 音乐链路未接入主流程**。`music_service/ace_music.py` 是库，没有调用方。
6. **`/v1` 不支持函数调用**。请求方的 `tools` 字段被忽略，工具由小焦自己调度。
7. 部分能力依赖可选组件（ComfyUI、语音模型、SD1.5 权重、N.E.K.O.），缺失时对应功能不可用，
   其余功能不受影响。
