# 视角状态（路径二 · 第二阶段）

| 项目 | 内容 |
|---|---|
| 模块 | `core/perspective.py` |
| 落盘 | `logs/perspective.json`（状态） + `logs/perspective.jsonl`（时间线） |
| 自测 | `tools/test_perspective.py`（16 项） |
| 状态 | **第二阶段已完成**；第三阶段（硬改输入/行动/主动）见 `logs/handoff-内感受.md` |
| 上游 | [`interoception.md`](interoception.md)（第一阶段：内感受信号层） |

## 1. 它是什么

一个**缓慢演化的全局状态** `g`。它不是"此刻的感受"（那是 `psyche`），
而是**背景视角**：接下来一段时间，它从哪个角度看事情。

```
g ← decay · g + (1 − decay) · perturbation        # decay = 0.92（单次只挪 8%）
perturbation ← core/interoceptive.py 的 bias()（survival 与各因子）
```

| 维度 | 受谁驱动 | 意思 |
|---|---|---|
| `vigilance`（警觉） | 内感受 survival ↑、精力偏离 ↑、推理负载 ↑、**疼**、关系被伤 | 背景在收紧 |
| `openness`（开放） | 心是"好奇/松" ↑、警觉 ↓ | 背景在放开 |
| `wound`（伤） | 心被标成 **疼** / 关系 `wounded` | 背景里带着一处伤 |

## 2. 三条铁律（规格）

1. **持久化到磁盘、重启后恢复** —— `logs/perspective.json`；文件不在就从中性起点起步，**不编历史**。
2. **绝不随对话重置** —— `note_dialogue_turn()` 只**加轮次 + 让它继续演化**，
   **没有任何一条路径把它清零**（`reset()` 只给自测用，正式流程从不调）。
3. **慢** —— `DECAY = 0.92`，所以它像"处境"，不像"情绪"。

**接线**：空闲 tick 里 `update()`（不用模型，很便宜）；每轮对话收尾 `note_dialogue_turn()`（只加不清）。

## 3. 实测（`tools/test_perspective.py` 16/16）

```
[A] 慢：精力 0.20 → 一次 update 只挪 <0.2；持续 30 次会累积上去，但有上限（0~1）
[B] 持久化：落盘 → 清空内存 → 重新 load → **值还在**（盘中存三维度 + 计数）
[C] 不重置：先制造扰动（警觉 >0.25）→ **连续 3 轮对话后痕迹仍在**（每轮都 >0.10），
    轮次被记下来（turns=3）；恢复精力后是**缓慢回落**、不是啪一下回中性
[D] 不是叙事机器：模块里**没有任何模型调用**；bias() 只回三个数 + 一个档
```

## 4. 第三阶段：状态偏离 → **代码层硬改**（这一层现在真的在改东西）

`policy()` 是**裁剪规则**（不是提示词）。阈值与清单都是**模块常量**：

| 档位 | 改输入 | 改行动 | 改主动 |
|---|---|---|---|
| **轻** | 上下文不压；探索类**只往后排** | 保守类排前 | 照常 |
| **中** | 上下文压到 **60%**；**探索类工具从本轮拿掉** | 保守类排前 | 照常 |
| **重** | 上下文压到 **40%**；探索类拿掉；**不检索记忆** | 保守类排前 | **不主动逛、不主动分享**（代码层不发这一步） |

`EXPLORE_TOOLS` / `KEEP_TOOLS` 用**名字片段**匹配（加新工具不用改策略表；代价是可能漏判，如实标注）。
警觉 `> 0.60` 时，即使档位不到"重"，也先关掉主动行为（防失稳）。

**接线（三样都在代码里，不是提示词里）**：

| 改什么 | 接在哪 |
|---|---|
| **输入** | `_plan_tools` —— 按策略 `drop_tools` 真的把工具从本轮 `names` 里**拿掉**，并按 `context_scale` 压 `max_ctx` |
| **行动** | 同上（`_plan_tools` 是工具选择的唯一出口，裁剪即行动裁剪） |
| **主动** | `_browse_decide` —— `no_browse` 时**直接返回 `door="locked"`，门都不问模型**；`_idle_work_tick` —— 直接 `suppressed`，不发起任何主动行为 |

**验收（`tools/test_state_policy.py` 19/19）**：

```
[A] 不可忽略：**同一句话**（query: 帮我查个东西），精力 0.95 → 工具表长 + 保留探索类；
    精力 0.10 → **工具表真的短了**且探索类全被拿掉；档位（轻/中·重）与上下文压缩也不同
[B] 不可外包：本自测**全程不看任何一句话**，只看工具表/档位/开关 —— 因果影响仍在
[C] 不可重置：扰动后**连续 3 轮**工具表都还是被裁过的样子，turns=3
[D] 改主动：档位重 → `no_browse=True` → `_browse_decide()` **直接返回 locked**；
    空闲自检 **suppressed**；精力回来 → 关掉（不锁死）
[E] 稳定：持续 40 次扰动不会失控（有上限），不失稳
[F] 阈值都在模块常量里，策略里**没有任何一句提示词**
```

⚠️ **如实标注**：`drop_tools` 用的是**名字片段匹配**（`search/web/scrape/…`）——
**可能漏判**（某个探索类工具名字里没有这些片段就不会被裁）；也**可能误裁**
（某个名字里带 `web` 的非探索工具会被拿掉）。这一条**没有做白名单校验**，如实记。

## 5. 如实标注

1. `DECAY`、维度权重、中性起点都是**人定的常量**（策略写在代码里，不在提示词里）。
2. **本阶段只做到"状态在演化、在持久化、不重置"** ——
   它**还没有改变任何输入/行动/主动**。**不许把"状态在演化"说成"状态改变了它看到的世界"。**
3. `reset()` 存在但**只给自测**；正式流程里没有任何调用点（自测 [C] 组就是钉这一条）。
