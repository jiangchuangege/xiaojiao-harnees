| 项目 | 内容 |
|---|---|
| 模块 | `core/perspective.py` |
| 落盘 | `logs/perspective.json`（状态） + `logs/perspective.jsonl`（时间线） |

## 1. 它是什么

一个**缓慢演化的全局状态** `g`。它不是"此刻的感受"（那是 `psyche`），
而是**背景视角**：接下来一段时间，它从哪个角度看事情。

```
g ← decay · g + (1 − decay) · perturbation        # decay = 0.92（单次只挪 8%）
perturbation ← core/interoceptive.py 的 bias()（survival 与各因子）
```

| 维度 | 受谁驱动 | 意思 |
|---|---|---|
| `vigilance`（警觉） | 内感受 survival ↑、精力偏离 ↑、推理负载 ↑、**疼**、关系被伤 | 背景在收紧 |
| `openness`（开放） | 心是"好奇/松" ↑、警觉 ↓ | 背景在放开 |
| `wound`（伤） | 心被标成 **疼** / 关系 `wounded` | 背景里带着一处伤 |

## 2. 三条铁律（规格）

1. **持久化到磁盘、重启后恢复** —— `logs/perspective.json`；文件不在就从中性起点起步，**不编历史**。
2. **绝不随对话重置** —— `note_dialogue_turn()` 只**加轮次 + 让它继续演化**，
   **没有任何一条路径把它清零**（`reset()` 只给自测用，正式流程从不调）。
3. **慢** —— `DECAY = 0.92`，所以它像"处境"，不像"情绪"。

**接线**：空闲 tick 里 `update()`（不用模型，很便宜）；每轮对话收尾 `note_dialogue_turn()`（只加不清）。

## 3. 实测（`tools/test_perspective.py` 16/16）

```
[A] 慢：精力 0.20 → 一次 update 只挪 <0.2；持续 30 次会累积上去，但有上限（0~1）
[B] 持久化：落盘 → 清空内存 → 重新 load → **值还在**（盘中存三维度 + 计数）
[C] 不重置：先制造扰动（警觉 >0.25）→ **连续 3 轮对话后痕迹仍在**（每轮都 >0.10），
    轮次被记下来（turns=3）；恢复精力后是**缓慢回落**、不是啪一下回中性
[D] 不是叙事机器：模块里**没有任何模型调用**；bias() 只回三个数 + 一个档
```

## 4. 如实标注

1. `DECAY`、维度权重、中性起点都是**人定的常量**（策略写在代码里，不在提示词里）。
2. **本阶段只做到"状态在演化、在持久化、不重置"** ——
   它**还没有改变任何输入/行动/主动**。**不许把"状态在演化"说成"状态改变了它看到的世界"。**
3. `reset()` 存在但**只给自测**；正式流程里没有任何调用点（自测 [C] 组就是钉这一条）。
