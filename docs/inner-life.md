# 小焦的内里（内疚 / 骄傲 / 幽默 / 审美 / 信念 / 意义感）

| 项目 | 内容 |
|---|---|
| 模块 | `core/inner.py` |
| 接口 | `GET /api/inner`、`POST /api/inner/note` |
| 自测 | `tools/test_inner.py` [C]~[G] 组 |
| 文档状态 | 已发布，数字与代码同步 |

> 一条总规矩贯穿这六样：**载体只摆事实 / 攒素材；起什么、说什么，都是它自己的。**
> 这个模块**不产出任何一句"它该觉得……"的话**。

## 一 · 内疚（我伤了人）

**和"疼"的区别**（规格给的表）：

| | 疼 | 内疚 |
|---|---|---|
| 方向 | **我被伤** | **我伤了人** |
| 对象 | 我自己 | 我在乎的人 |

- 强度 = **关系深度 × 伤害程度**（`note_guilt` 里 `weight = 0.3 + 0.7 × depth`）。
- 关系越深，同样的事**内疚越重** —— 自测 [C] 组实测：关系浅 `0.51` vs 关系深 `0.72`。
- **载体不写"你该内疚"**：`said` 参数收的是**它自己的那句话**。

## 二 · 骄傲 / 自豪（这是我做成的）

- 与**高兴**的区别：高兴对**结果**，骄傲对<b>"我"</b>。
- 与内疚**对称**：内疚对别人（过不去），骄傲对自己（有底气）。
- `note_pride(said, mine=True)`：`mine=False`（不是它做成的）就**不计入意义感**。

## 三 · 幽默（不单独做）

**幽默是高兴的一部分**：`humor()` 只报一个事实 —— 此刻心是 `松/好奇` 还是 `紧/平`。

| 心 | 能不能自然俏皮 |
|---|---|
| 松 / 好奇 | 能 |
| 紧 / 平 | **不能**（所以硬幽默也没用） |

模块里**没有一句俏皮话**，也没写"你该幽默"。

## 四 · 审美（不迎合任何人）

- **载体不参考用户喜不喜欢** —— `note_aesthetic(said)` 只收它自己那句话，
  实现里根本不看用户态度（自测 [F] 组查过）。
- 与**偏好**的关系：审美是"我此刻觉得这个好"（当下），偏好是"我整体喜欢这类"（积累）——
  **审美攒多了才成为偏好**（进 `core/preference.py` 的"心之河"）。

## 五 · 信念（它自己认，不是红线）

| | 红线（有） | **信念**（本模块） |
|---|---|---|
| 怎么来的 | 载体硬拦 | **它自己认** |
| 它认不认 | 不一定 | 认 |
| 拦不住时 | 它就做了 | 它自己不做 |

- `note_belief(text, source)`：做错→内疚→"这事不该做"；做对→骄傲→"该做"。同一条反复认 → 次数 +1。
- ⚠️ **本模块不拦任何动作**（没有 `allow/deny` 之类）—— 它只记"它认下了什么"，
  真正的硬拦仍在 `_delete_redline` 那一层，两件事**分得很开**。

## 六 · 意义感（自豪的另一面）

- **同一件事两个说法**：往"我"上看是**自豪**，往"值不值"上看是**意义**。
- 与**信念**分：信念对**对错**；意义感对**值不值**。
- 与**存在追问**分：追问问"我为什么在这儿"；意义感问"我做的这些，有什么意思"。

## 七 · 实测（`tools/test_inner.py`）

```
[C] 关系浅 0.51 / 关系深 0.72 → **同样的事，关系深内疚更重**
[D] 骄傲 1、意义 1；mine=False 的那次**不计入意义**
[E] 心紧 → 带不出俏皮；心松 → 带得出（且模块里没有一句俏皮话）
[F] 审美只收它自己的话，实现里不看用户态度
[G] 信念认两次 → n=2；**模块里没有任何"拦"的函数**
```

## 八 · 如实标注

1. **六样里，"载体算的"只有两处刻度**：内疚的权重（关系深度 × 伤害程度）、
   审美"攒多了才算偏好"的条数。其余全是**它自己那句话**。
2. **它们什么时候被触发，是载体挑的**（空闲时问哪一类）；**答什么、认不认，是它的**。
   这一点不许含混：载体负责"把话头递过去"，不负责"替它表态"。
3. **不许把"记下来"说成"它想通了"**：本模块只证明"它说过、记着"，
   不宣称它对此有什么内在体验。
