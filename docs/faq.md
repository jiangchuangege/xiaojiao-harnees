## 1. 为什么裸模型自称 Qwen

这是正常现象。小焦的"大脑"默认是 Qwen 系权重，小焦是套在它外面的一层壳，负责人设、工具与记忆。

- 直接连裸模型（llama-swap 上游的 llama-server）→ 得到模型自己的出厂回答；
- 连小焦的 `/v1` 或网页 → 人设层被注入，回答来自"小焦"。

需要小焦人格时走 `/v1` 或网页。

## 2. 能换成别的模型吗

能。「设置」→ 模型管理 → 添加，填任意 OpenAI 兼容接口（名称、类型 `api` / `llama` / `xiaojiao`、BaseURL、API Key、模型名）。添加后出现在顶部下拉框，可随时切换。人格与工具属于壳，换底座不影响。

## 3. 工具不执行或不干活

按顺序检查：

1. 界面上方的「工具」开关是否为开（读写接口为 `/api/tools_toggle`，开 = 允许执行工具，关 = 只聊天）；
2. 要求的是否属于"执行类操作"（建文件、写文件、跑命令），而不是纯聊天；
3. 聊天大脑是否在线：本地大脑由 llama-swap（默认 9292）托管，未在线时工具链可能不可用；
4. 对话中该轮是否被意图收窄成闲聊：`_detect_intent()` 会把认不出的输入归为 `chat`，此时只发少量工具。把需求说具体即可。

## 4. 刷新后会话消失

不会。会话与历史都写入磁盘（`xiaojiao_sessions.json`、`xiaojiao_history.json`），刷新后在左侧列表点回对应会话即可，接口为 `GET /api/sessions` 与 `GET /api/session/<sid>`。

## 5. 让它建文件，文件名不对

不要切到 `xiaojiao` 引擎，`brain.engine` 保持 `auto`（或 `llama`）：人设里包含"严格使用指定文件名"的约束，小模型容易忽略。若仍出错，重启一次大脑再试。

## 6. 报 CUDA OOM

调小上下文窗口：`xiaojiao_control.json` → `brain.llama.ctx`，例如 32768 降到 16384。仍不够时改用云端接口（`brain.engine` 设为 `api`）。

## 7. 云端 API 报 `Invalid token` 或模型调用出错

先用体检工具定位，不要凭感觉改配置：

```powershell
python tools/check_cloud_brain.py               # 体检当前配置
python tools/check_cloud_brain.py --key sk-xxx  # 临时测另一把 Key（不写配置）
python tools/check_cloud_brain.py --n 10        # 每组多打几次（默认 6）
```

它的判据只有一条：`POST /chat/completions` 能不能通。

| 体检结果 | 含义 | 怎么办 |
| --- | --- | --- |
| chat 全通 | 配置正确 | 无需处理 |
| chat 时通时不通 | 网关偶发拒签（服务商侧抖动） | 小焦已内置退避重试与本地大脑兜底，稍后再试 |
| chat 全部超时且无一次被拒 | Key 有效，对方响应过慢 | 换更快的模型或稍后再试，期间由本地大脑顶着 |
| chat 一次都没通 | 这把 Key 在服务商侧未被接受 | 按下表四条顺序排查 |

`GET /models` 不能当作证据：实测连空 Key、随意拼写的 Key 都偶发返回 200（网关或缓存有时不校验令牌），所以"models 能通"不等于"Key 是对的"。

chat 一次都没通时，按顺序排查：

1. 这把 Key 是否就是你其它客户端里能用的那把（最常见的是复制到旧 Key、少了几位）。最快验证：`python tools/check_cloud_brain.py --key <你确认能用的那把>`；
2. 该 Key 已失效、被停用，或额度用完；
3. 账号需要在服务商控制台激活该模型或子账号权限；
4. 对方网关故障，把体检输出里的 request id 报给服务商支持确认。

小焦自身的自动处理（无需配置）：

| 机制 | 行为 |
| --- | --- |
| 退避重试 | 对 400 / 401 / 402 / 403 / 404 / 429 / 500 / 502 / 503 重试，最多 4 次尝试，间隔 0.7s → 1.4s → 2.1s |
| 超时不重试 | 云端单次请求 15 秒未回即改用本地大脑，避免用户长时间干等 |
| 自动兜底 | 云端不可用时改用本地大脑回答，并在回答末尾注明"本次回答由本地大脑完成 + 真实原因 + 最近 N 次成功 K 次" |
| 错误转述 | 服务端返回的 JSON 错误被收拾成一句可读中文，例如 `HTTP 401 · API Key 无效或已过期（服务端说：Invalid token）`，并隐去密钥 |

官方排查清单（base_url、Bearer 格式、401/429 含义）见 [Agnes TROUBLESHOOTING](https://github.com/AgnesAI-Labs/AgnesAI-Models/blob/main/docs/TROUBLESHOOTING.md)。

## 8. 怎么让它更聪明

换更强的底座模型，或加大 `brain.llama.ctx`。人设、工具、记忆这套壳不需要改。
