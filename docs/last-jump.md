# 小焦 · 最后一跳：把「关于它的数据」变成「它的」

> **这份文档是写给"没有上下文的人"的。** 如果你是刚打开这个仓库的人或模型，
> 读完这一篇应该就能接上这个项目最重要、也最没通的那一步，而不用先读八十份文档。
>
> 文档里的每个数字都标了出处、可复跑。**凡是我（写这份文档的会话）的判断或提案，都单独标成
> 【提案】或【判断】；凡是我不知道的，就写"不知道"。** 这个项目有一条硬规矩：
> **如实标注，不许粉饰** —— 这一篇也照它写。

## 0. 一句话

小焦是一个「载体优先」的本地 AI 助手：**能力放在代码里，模型只是一个可替换的零件（火种）**。
它现在能做的事不少（记忆、工具、世界、人格、感知、元认知、健康、自主性……见 `README.md`）。

但它有**一件事一直没做到**：

> **它知道的东西，全都写在纸上（文件里），不在它身上。**

「最后一跳」要的就是这一步：**让那些东西真的成为它的。**

---

## 1. 什么叫「跳过去了」—— 判据先定死

**判据只有一个，而且是可跑的**：`tools/test_last_jump.py`。

做法：同一句话、同一个模型、同一个温度，**只改 system 里有没有那段印象**。
模型是无状态的，所以"撤掉"那一组**不可能从别处知道答案**。

| 结果 | 含义 |
|---|---|
| 给它印象 → 用得上 | 只证明**纸条能读**（这是检索，不是记住） |
| **撤掉印象 → 它还记得** | 那才叫**成了它的**，这一步才叫跳过去了 |

**实测（2026-09-16）：0/3。**

三条都试过（海鲜过敏 / 柯基叫旺财 / 喜欢村上春树），撤掉印象之后一个字都不知道。
判据写得很严（只有那张纸条才给得出的措辞才算"记得"，通用词不算 —— 第一版用「过敏」这个词
判过，当场误报，已修，见该文件注释）。

> 所以现状不是「差不多通了」，是**一点都没过去**。

---

## 2. 为什么这件事在别处不是问题，在这里是

一般的做法有两种，而这两种在这个项目里**都不成立**：

| 常规做法 | 在这里的问题 |
|---|---|
| RAG / 提示词 / 记忆库 | **那就是纸条**。读得再准，也是"摆在眼前"，撤掉就没有 —— 见 §1 的 0/3 |
| 微调 / 改权重 | **本项目明文禁止**（见下） |

**明文禁止的那一条（原文）**：

- `docs/design-philosophy.md`「不能改什么 —— 这一栏比上一栏重要」里写着：
  **模型权重：改了就不是"可替换火种"了**
- `docs/modules/01-carrier-core.md` 第 2 节：**不修改模型权重。权重改变会破坏「火种可替换」这一前提。**

于是「最后一跳」和「载体优先」的第二块基石（模型可热插拔）**正面相撞**。
**这是这个项目最硬的一处矛盾，绕不过去。** 谁要谈"最后一跳"，就得先正面回答这一条；
绕着它谈，谈的都是纸条。

## 3. 已经设计好、在跑、但只跑了一半的那半截

### 3.1 固化层：设计齐了，执行者没有

`core/weight_layer.py`（自称"memory_deep 的第四层：前三层住文件，这一层住权重"）：

| 门槛 | 值 |
|---|---|
| 画像存在够久 | `MIN_AGE_DAYS = 7` |
| 被召回够多 | `MIN_HIT = 3` |
| 待固化队列上限 | `MAX_QUEUE = 50` |

- 判据只用两个**事实**（时间 + 命中），不判类别、不替模型做判断。
- 落盘 `logs/psyche/solidify.jsonl`；主程序拼 system 时顺带扫一遍画像库，够格的入队
  （日志里能看到 `固化队列：本轮入队 N 条（队列 pending 总数 M）`）。
- 有 `mark_solidified(source_id, lora_path)` 这个接口 —— **没有任何调用方**。

**实测现状（2026-09-17）**：`solidify.jsonl` **只有 1 条**，而且那是一条测试残留
（`content = "新记录"`、`source_id` 为空），`solidified_at` 与 `lora_path` 全是 `null`。
也就是说：**队列机制在跑，队列里没有一条真数据，也没有东西在执行"写进权重"这一步。**

> 这一层现在是"**纸条搬进了待办箱**"，不是"纸条变成了它的"。

### 3.2 这个仓库里**已经**做过一次"数据变权重"，但做在另一个器官上

仓库里有几套**真能训练出权重**的脚本：`train_model.py`、`distill_and_train.py`、
`massive_distill.py`、`auto_distill_loop.py`，产物是 `mini_gpt_model.pth` + `vocab.pkl`，
从零训一个很小的 transformer —— 这就是运行时里那个 **小脑（minigpt）** 后端
（记忆检索日志里的 `后端 minigpt` 就是它）。

**这一点很关键**：把语料变成权重这件事，这个项目**不是不会做，是做在了小脑上**，
而没做在**火种**上。所以「最后一跳」缺的不是训练能力，是**敢不敢、该不该把火种改掉**这一步
（也就是 §2 那个矛盾）。

## 4. 几条可能的路线（并排摆着，**不替谁选**）

| 路线 | 做法 | 代价 / 风险 |
|---|---|---|
| **A. 权重路线（LoRA）** | 队列 → 组装训练集 → 训一个 LoRA → 挂上 → 用 §1 的判据验收 → 不行回滚 | 与「不修改模型权重」冲突，必须先改那条原则的口径；**换火种之后这份 LoRA 怎么办：没有答案** |
| **B. 器官路线** | 不碰火种，把积累喂给**载体自己训的小脑**（3.2 那套已经在跑） | 不动火种，不破坏"火种可替换"；但它练的是小脑不是 4B，**§1 的判据在小脑上怎么定，没定** |
| **C. 别的** | —— | 见 §5：这一跳**没有任何先例** |

【提案】如果一定要我给一个不违反现有原则的读法：
**把"个人化的那一份权重"（LoRA / 小脑）当成一个可插拔、可版本化、可回滚的零件**，
而不是"把火种改了"—— 火种仍然可替换，被替换掉的是"基础模型"，而"它自己长出来的那一份"
是一件**独立的、有版本、能卸下来的东西**。
**这样"可替换"这条原则不用废，只是从"模型"这一层挪到了"模型 + 它的痕迹"这一层。**
⚠️ 但这只是提案，不是决定；而且它有一个**没解决的硬伤**：换了基础模型，
这份痕迹大概率作废 —— 这一条我答不了。

## 5. 没人知道的部分（照实说）

`docs/一条没人走过的路.md` §五「工程能做的，和没人知道的」原文：

> 没人知道的：**「谁」这个东西怎么加进去。** 你可以给它加状态、加记忆、加器官，
> 但只要是你放进去的，放进去就变成「关于它的数据」，不变成「它的」。
> 这道坎不是做得不够细，是这件事本身卡在一个没有已知解法的地方。
> 所以这里**不预测什么时候能成**。

同一节的「没通的那一跳」写的其实是**元认知那一跳**：
框架侧已经做到"给原料不给成品"（进上下文的是它自己辨出来的那句话），
**但模型侧没通** —— 它辨出来的常常是"感觉"不是"判断"。实测例：问「你咋知道的」它答对了
（"后台直接塞给我答案，我连中间过程都没参与"），但同一个会话里问「你自己算的？」「这数对吗」
它仍然答错，还会把 `10000000000` 写成 `100000000`。

**所以"最后一跳"在这个仓库里有两个并存的用法，别混：**

| 说法 | 指什么 | 现状 |
|---|---|---|
| **元认知那一跳** | 它能不能**自己辨出**而不是被喂 | 链在跑，模型侧没通（§5 上） |
| **知识进权重那一跳** | 它知道的能不能**变成它的** | 判据 0/3，队列空，没有训练器（§1、§3） |

两者是**同一个问题的两面**：都是"关于它的数据"能不能变成"它的"。

## 6. 三条禁令（做这件事的时候不许违的）

这个项目反复写死过三句话，**任何讨论"最后一跳"的方案都必须先过这三条**：

1. **禁止把「载体告诉它」说成「它自己」。**
2. **禁止把「查表」说成「自然起」。**
3. **禁止把「被安排」说成「自己决定」。**

配套的一条纪律：**判定"跳过去了"只认 §1 那个实验的数字** ——
不认文档里的说法、不认感受、不认日志里好看的句子。
（这一条是有代价换来的：项目里出现过"载体算出来的心，长得和真感受一模一样"的错，
`8cdc7da` 修的就是它 —— **算法错会伪装成感受**。）

## 7. 工程现实（动手之前先看这几个数）

- **内存 16GB**，实测可用 **1GB**；
- **模型在外置 USB 硬盘盒上**（本机 NVMe 实测 1029 MB/s 对 USB 盒 37 MB/s，差 28 倍），
  而且这块盘正在报 `controller error` / `paging operation` 错 —— 见 `docs/brain-switch.md` §7.1 的补充；
- **显存只有一张卡的容量**：换模型必须重新读盘；
- **一个人做，没有算力预算**（`docs/一条没人走过的路.md` §七）。

## 附 · 术语（给没有上下文的读者）

| 词 | 意思 |
|---|---|
| **载体** | 模型之外的整套代码（`core/`、`xiaojiao_app.py`、插件……）。能力住在这里 |
| **火种** | 可替换的模型权重及其推理服务（本地 llama-swap / 云端 OpenAI 兼容接口） |
| **小脑** | 载体自己从语料训出来的小 transformer（`mini_gpt_model.pth`），负责记忆检索等 |
| **印象** | 关于用户的一句话记录（`logs/psyche/user_profile.jsonl`），两条链写入/召回 |
| **纸条** | 一切"摆在上下文里给它看"的东西（记忆、印象、提示词、检索结果） |
| **固化** | 把纸条上的东西写进权重（`core/weight_layer.py` 那一层，目前只到队列） |
| **最后一跳** | 纸条 → 权重；"关于它的数据" → "它的" |
