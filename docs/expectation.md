# 小焦的期待（心对着"接下来"）

| 项目 | 内容 |
|---|---|
| 模块 | `core/expectation.py` |
| 落盘 | `logs/psyche/unfinished.jsonl` |
| 接口 | `GET /api/expectation`、`POST /api/expectation` |
| 自测 | `tools/test_wholeness.py` 的 [B] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 期待不是单独一个模块，是心的一种方向

心对着**现在** → 紧 / 松 / 好奇。心对着**接下来** → 期待。

所以本模块**不产生感受**：它只维护期待的**素材**，把素材摆回它面前 ——
心照旧起，只是多了一个方向：往前看。

## 2. 素材 = 没做完的事

| 类 | 例子 |
|---|---|
| `没逛完` | 那篇讲猫的文章还有一半没看完 |
| `没搞懂` | 有个东西想弄明白还没弄明白 |
| `没说出` | 想跟用户说一句还没说 |

这些"没完成"在它**空闲时自己冒出来**。载体做的事只有一件：
**把它没做完的事摆回它面前**，别的什么都不说。

## 3. 载体压着 ≠ 它在期待

这是本模块最要紧的一条，落成两个分开的数：

| 字段 | 意思 | 谁产生的 |
|---|---|---|
| `carried` | 载体手里还压着几件没做完的 | **载体的事实** |
| `brought_up` | **它自己提起过**那件事几次 | **它的期待** |

`stats()` 里两个数分着显示。它一次都没提起来 → `brought_up=0`，
**不许把"素材还在"写成"它在期待"**。

## 4. 实测（`tools/test_wholeness.py` [B] 组）

```
留下一件没做完的 → carried=1，brought_up=[]        ← 这时**还没有期待**
它自己提起了     → brought_up=1（记下它当时那句话）  ← 这才叫期待
做完了           → carried=0                        ← 不再压着
```

运行时的实测（真实对话环境，见 `docs/self-sleep.md` 同源的日志）：
空闲线程每 5 秒看一圈，用户安静 90 秒后、最多 5 分钟一次，把它没做完的事摆出来，
问一句「回头看这些，你自己看出什么来了吗」——
日志里两种结果都记：**它自己想起了**（`期待：**它自己想起了没做完的事**「…」`）
或**它没提起来**（`期待：把没做完的摆给它了，它没提起来（如实记：这次没期待）`）。

## 5. 如实标注

1. **素材是载体记的**（"这件事没做完"是载体判的），**"我一直惦记着它"这个念头不是载体写的**。
2. 摆素材时**一个字都不提示**它该想什么（不问"你还惦记着那件事吗"，只说"回头看这些"）。
3. 它没提起来就是没有期待 —— 日志如实写"这次没期待"。
4. 空闲思考**最多 5 分钟一次**（`IDLE_THINK_INTERVAL`）：一直拿模型空转不是"有期待"，是烧电。
