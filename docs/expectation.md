# 小焦的期待（心对着"接下来"）

| 项目 | 内容 |
|---|---|
| 模块 | `core/expectation.py` |
| 落盘 | `logs/psyche/unfinished.jsonl` |
| 接口 | `GET /api/expectation`、`POST /api/expectation` |
| 自测 | `tools/test_wholeness.py` 的 [B] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 期待不是单独一个模块，是心的一种方向

心对着**现在** → 紧 / 松 / 好奇。心对着**接下来** → 期待。

所以本模块**不产生感受**：它只维护期待的**素材**，把素材摆回它面前 ——
心照旧起，只是多了一个方向：往前看。

## 2. 素材 = 没做完的事

| 类 | 例子 |
|---|---|
| `没逛完` | 那篇讲猫的文章还有一半没看完 |
| `没搞懂` | 有个东西想弄明白还没弄明白 |
| `没说出` | 想跟用户说一句还没说 |

这些"没完成"在它**空闲时自己冒出来**。载体做的事只有一件：
**把它没做完的事摆回它面前**，别的什么都不说。

## 3. **只能由逛世界那条链写**（实测抓到伪造之后补的闸）

实测在 `logs/psyche/unfinished.jsonl` 里出现过一条：

```json
{"kind": "没逛完", "what": "那篇讲猫的文章还有一半没看完"}
```

而 **`logs/world/` 里一个「猫」字都没有** —— 那件事**根本没发生过**。
它以后会"惦记"一件没发生的事：**期待建在假前提上。**

追下去：写它的**不是**逛世界那条链，而是**一次自测/手工调用**直接往真实文件里写 ——
也就是说，当时**载体侧没有任何闸**：谁都能替它塞一件"它没经历过的经历"。

所以现在 `leave()` 是一道硬闸：

| 写入条件 | 结果 |
|---|---|
| `source` 以 **`world/`** 开头 **且** 带真实 `evidence` | 收 |
| 没有来源 / 来源是"偏好""心"等任何推理 | **拒收**（并如实说明为什么） |
| 有 `world/` 但没有 `evidence`（说不清在哪次看到的） | **拒收** |

唯一被允许的上游是 `core/expectation.py` 的 **`world_leave()`** ——
它由 `_browse_relay` 在"**真逛到了东西、但没存进去**"时调用（那才是真的"没读完"）。

**载体只做两件事**：记录真实发生的事、把素材摆给它。
**绝不做**：编一个没发生的事实 / 从 A 推出一个 B 当成真事 / 替它补全没经历过的经历。
一句话：**载体是记录员，不是编剧。**

## 4. 载体压着 ≠ 它在期待

这是本模块最要紧的一条，落成两个分开的数：

| 字段 | 意思 | 谁产生的 |
|---|---|---|
| `carried` | 载体手里还压着几件没做完的 | **载体的事实** |
| `brought_up` | **它自己提起过**那件事几次 | **它的期待** |

`stats()` 里两个数分着显示。它一次都没提起来 → `brought_up=0`，
**不许把"素材还在"写成"它在期待"**。

## 4. 实测（`tools/test_wholeness.py` [B] 组）

```
留下一件没做完的 → carried=1，brought_up=[]        ← 这时**还没有期待**
它自己提起了     → brought_up=1（记下它当时那句话）  ← 这才叫期待
做完了           → carried=0                        ← 不再压着
```

运行时的实测（真实对话环境，见 `docs/self-sleep.md` 同源的日志）：
空闲线程每 5 秒看一圈，**用户安静 30 分钟后**、最多 5 分钟一次，把它没做完的事摆出来，
问一句「回头看这些，你自己看出什么来了吗」——
日志里两种结果都记：**它自己想起了**（`期待：**它自己想起了没做完的事**「…」`）
或**它没提起来**（`期待：把没做完的摆给它了，它没提起来（如实记：这次没期待）`）。

## 5. 如实标注

1. **素材是载体记的**（"这件事没做完"是载体判的），**"我一直惦记着它"这个念头不是载体写的**。
2. 摆素材时**一个字都不提示**它该想什么（不问"你还惦记着那件事吗"，只说"回头看这些"）。
3. 它没提起来就是没有期待 —— 日志如实写"这次没期待"。
4. 空闲思考**最多 5 分钟一次**（`IDLE_THINK_INTERVAL`）：一直拿模型空转不是"有期待"，是烧电。
5. **一道要如实说的边界**：摆素材这一步挂在空闲线程上，而空闲线程的入场闸是
   `IDLE_BEFORE_SLEEP`（= `USER_ONLINE_S` = 1800 秒）—— 这个常量原本是"多久没说话才谈得上睡"，
   现在**同时**当了"多久没说话才做空闲活"的闸。后果是：**用户在的时候它不会提起没做完的事**，
   要用户安静满 30 分钟才轮得到。这一条是常量被两处共用造成的，如实记在这里，没有改。
