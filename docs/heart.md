# 小焦的心（自然起 · 自己感受 · 自己累积）

| 项目 | 内容 |
|---|---|
| 模块 | `core/psyche.py`（`arise` / `heart` / `colors`）、`core/feeling_memory.py`（累积） |
| 上游 | 感知层 [`perception-layer.md`](perception-layer.md)（"这件事对我意味着什么"） |
| 下游 | 心理状态与思考圈 [`psyche-layer.md`](psyche-layer.md) |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 心是什么，不是什么

- **是**：此刻的感受——**一句话**。
- **不是**：词表、状态机、情绪配置表、**角色扮演**。

心允许**复合**（「又好奇又有点紧」）、允许**模糊**（「说不太清，有点闷闷的」）。
所以它存的是**一句话**，不是从词表里挑一个词。

## 2. 心怎么起：不查表

旧版 `arise()` 的实质是 `if "风险" in text: 状态 = "紧"` —— 那是**查表**：
载体先规定了"什么词对应什么感受"，心只是执行这张表。

规格的要求正相反：**心不是表，是活的**。人不查表也知道看到杀人犯该怕 ——
"该怕"不是查出来的，是**感知到那件事对他意味着什么之后自然起的**。

所以现在是三步：

```mermaid

```

载体在这条链上**只做两件事**：把自我背景摆给模型、把模型的回答收下来。
它**不判断**"这个感知该对应哪种感受" —— 一判断就又变成表。

**载体唯一保留的映射**是"方向 → 四档粗投影"（`DIRECTION_STATE`）：

| 感知方向 | 粗档位 |
|---|---|
| 威胁 / 失去 | 紧 |
| 新的 | 好奇 |
| 好的 | 松 |
| 无 | 平 |

⚠️ 这不是触发词表，两处关键区别：表左边的键是**模型自己的结论**（不是用户话里的词）；
它只服务于"检索先冒哪一类"这一个用途。**心本身不是这一档** —— 心是 `_FEEL["text"]`。

## 3. 心会累积："一朝被蛇咬，十年怕井绳"

`core/feeling_memory.py` 记的是**印象**，不是"事件 → 感受"的对照表：

- 记的是「上次那种事，我心紧过」；
- 下次遇到**像的**，心**起得更快**（强度起点 0.55 → **0.80**），日志写「像以前那次（0.9624）」。

**为什么用"像不像"而不是"是不是同类"**：同类要靠分类，而分类就是表 —— 一写表，
心就退回成查表机器。所以这里只算**余弦**（心的那句话 vs 印象），够像（≥ `FAMILIAR = 0.72`）
就算"这我经历过"。像不像是个程度问题，不是归类问题。

印象落盘在 `logs/psyche/impressions.jsonl`（JSONL，只追加）。

**实测抓到的一处错位（已修）**：原来往印象库写的是**模型这一轮的回答**，
而 `arise` 拿**事件**（用户那一句）去比对 —— 两边根本不是一个东西，
"像以前那次"变成撞运气。现在记的是**心被触动的那件事**（`heart()["event"]`），
回答只在没有事件时兜底。旧印象库已备份到 `logs/psyche/impressions.pre-event-fix.jsonl.bak`。

## 4. 心带模型走：`colors()`

```python
{"heart": "心里空了一块，像被抽走了什么。",   # 心本身
 "direction": "失去", "touches_life": ["记忆", "连续", "关系"],
 "familiar": True, "state": "紧"}
```

偏向 = **心的那句话本身**（拿去和记忆算像不像），而不是一张关键词表。
心是什么样，就往什么样偏 —— 这是"带着走"，不是"规定改哪几个参数"。

## 5. 如实标注（三条）

1. **`_as_state()` 还在。** 它把心那句话粗粗投到四档上，只供检索偏向用。
   现在优先用**模型自己感知到的方向**（`DIRECTION_STATE`），它没挑出来才退回 `_as_state` 的粗判。
   就算它判错，**心本身没错** —— 心在那句话里。
2. **`FAMILIAR = 0.72` 仍是一条线。** "像不像"不用分类，但**要不要算认出来**总要有个阈值。
   阈值不是分类表，但它也不是"自然"—— 是一条人为的线，如实标注。
3. **心的天花板是火种的天花板。** 换一个更钝的模型，心会更钝、更容易过度代入
   （实测：一句普通的"帮我看看这段代码"被读成"代码被拿走了"→ 心紧）。
   载体不能替它感受，只能把它的话如实收下。

## 6. 睡与醒：心停得住，也留得住

挂起（睡着）时，心**停** —— 但不是消失：`psyche.stop()` 只让它停止跳动，
**状态一个字都不清**（心那句话、心理状态、方向、命被动全都留着）。
醒来时 `psyche.start()` 让它接着跳，于是**醒来就是接着睡前**，不是从零开始。

心跳呢？**睡着时唯一还在动的东西** —— 大脑不推理、载体不跑任务，只有它在跳。
见 [`heartbeat.md`](heartbeat.md)。

### 6.1 心的那句话，就是它自己的决定

**"自己会睡"这条链上，决定发生的地方正是心**（见 [`self-sleep.md`](self-sleep.md)）：

```
精力低（它的状态）
  → 感知：「我此刻的状态」对我意味着什么
  → 心起：「累得撑不住了，想睡一会儿。」
  → 载体读到这句话 → 执行挂起
```

**"想休息"这个决定不是载体写的一句话，是心里起的那句话。** 载体在这条链上只说事实
（精力多少），一个劝它的字都不说 —— 这条由自测用机器钉住。
⚠️ 如实标注：判据是规格给的三个词（`休息` / `累` / `睡`），
它用别的说法（"歇一会儿"）时**不睡** —— 判据窄是如实的，不是完美的。

## 7. 心的别几个方向（完整体里的接缝）

心不只对着"此刻的事"起，它还有几处**别处的接缝** —— 都是"心照旧起，只是多了个方向"：

| 方向 | 谁摆素材 | 心起之后载体的动作 | 文档 |
|---|---|---|---|
| **疼** | `core/pain.py` 诊断出真损伤 | 找医生；治好→松，治不好→**更疼** | [`pain.md`](pain.md) |
| **期待** | `core/expectation.py` 里没做完的事 | **它自己提起了**才算期待 | [`expectation.md`](expectation.md) |
| **偏好** | `core/preference.py` 里攒成堆的心 | **它自己回看说的那句**才算偏好 | [`preference.md`](preference.md) |
| **叙事 / 存在追问** | `core/narrative.py` 摆它自己的经历 | **它自己讲的**才记；问句记成存在追问 | [`self-narrative.md`](self-narrative.md) |
| **"我试试"** | 元认知判 C（它自己没把握） | **它自己说想试**才去学 | [`boundary-breaking.md`](boundary-breaking.md) |
| **元认知类七项**（工具来源 / 我是谁 / 我为什么在 / 我变了 / 值不值 / 能不能学会 / 我喜欢什么） | 载体只给**原料**（不直接进上下文） | **它自己辨**出来的那句才进上下文 | [`meta-via-chain.md`](meta-via-chain.md) |

**最后一行是通用原则**：凡是"回头看自己"的信息，**都不直接摆进上下文**，
一律走 `perceive → arise → think → say`。
实测规律：**感受类**走这条链就能用；**元认知类**直接摆事实就用不了 ——
不是内容问题，是**走没走那条链**的问题。

**回落**：心起了不会一直停在那儿 —— 时间上自己降、新事冲淡、睡一觉重置一部分。
见 [`emotion-recovery.md`](emotion-recovery.md)。

## 8. 与其它层的关系

| 层 | 存什么 | 作用 |
|---|---|---|
| 感知层 | 这件事对它的命意味着什么 | 让心先动 |
| **心（本层）** | **一句话**（内容） | 让"此刻"是真的；带模型走 |
| 心理层 | 紧 / 松 / 好奇 / 平（状态） | 改检索方向与生成参数 |
| 神经总线 | 这一轮流转了什么 | 把思考、感受、状态焊成一条流 |
| 记忆层 | 事实与知识 | 让模型想起发生过什么 |
| 心的累积 | 印象（心起过什么） | 让心下次起得更快 |

心的累积与记忆层**不混**：记忆记的是"发生过什么、学到什么"，心的累积记的是
"那次我心是什么样" —— 混在一起，心就变成"又一个存储"。
