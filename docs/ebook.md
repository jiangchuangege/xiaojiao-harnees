# 公开电子书采集：把「目录 → 条目 → 文件」走完

> 插件：`plugins/ebook.py` ｜ 工具：`ebook_manifest`、`ebook_grab` ｜ 自测：`tools/test_ebook_plugin.py`（27 项）

## 一、它解决的是什么

用户实测的那句话：**「帮我爬一下电子书 <网址> 下载到 G:\dzs」**。
原来的结果是 `screenshot` 连错两次、报"会话不存在"、整体「已停止」——三段链全断了：

| 环节 | 断在哪 |
| --- | --- |
| 意图识别 | 「下载/保存到」被当成"别的动作"，抓取意图直接判成空 |
| 抓取直通 | 命中专用工具 `download` → 通用 `get` 被隔离逐出 → 直通被跳过 |
| 结果落盘 | 没有任何代码把正文写到用户给的路径 |

前两段修在载体层（见 CHANGELOG「爬下来存到本地」），第三段就是本插件 + 载体的落盘链。

## 二、两个工具怎么用

### `ebook_manifest` —— 先看清这一页有什么

```
ebook_manifest({"url": "https://某个公开书站/books", "out": "G:\\dzs\\书目.csv", "limit": 50})
```

- 抓目录页，挑出**同站的条目链接**（自动排除 `/tag/`、`/page/`、登录注册、静态资源）；
- 书名优先取链接文字（链接文字通常就是书名），没有才退回文件名；
- 能存 `.csv`（Excel 直接开）或 `.md`（表格）；
- 只解析目录页，**不下载任何文件**。

输出示例：

```
📚 目录页解析结果（…/books）
共找到 4 个条目链接，先列前 4 条：

1. 公开书一（PDF）
   …/book/1.html
```

### `ebook_grab` —— 逐条进条目页，把文件下下来

```
ebook_grab({"url": "https://某个公开书站/books", "out_dir": "G:\\dzs", "limit": 10})
```

- 给**目录页**：逐条进详情页找文件直链，一条条目最多下 3 个文件；
- 给**详情页**：直接找直链并下载；
- 结果分三堆：**成功 / 跳过（写清原因）/ 失败（写清原因）**，绝不把"跳过"说成"已下载"。

输出示例：

```
📥 采集结果（…/books → G:\dzs）
成功 1 个：
- G:\dzs\a.pdf（125 字节）
  ← …/files/a.pdf
跳过 2 个（如实说明，不硬来）：
- …/book/2.html
  需登录/付费（页面出现：vip、会员、购买）→ 未采集
- …/book/4.html
  这一页没有公开的文件直链（pdf/epub/txt…）→ 未采集
```

## 三、三条边界（写死在代码里，不靠提示词）

1. **不碰付费墙 / 登录墙**：详情页一旦出现 `VIP / 会员 / 付费 / 购买 / 登录后 / 注册后 / 积分 / 扫码 / 提取码` 等信号，
   该条目**直接跳过**并写明命中了哪些词。不猜测文件路径、不伪造 Cookie、不试"会员专享"接口。
   **绕过付费墙不是能力，是侵权** —— 这条不做。
2. **遵守 robots.txt**：被 `Disallow` 的路径一律不抓，结果里写明「robots.txt 不允许抓这个地址」。
   读不到 robots.txt（404/超时）按允许处理（RFC 惯例）。
3. **只下白名单扩展名 + 验文件头**：`pdf/epub/mobi/azw3/txt/zip/djvu`；
   PDF 必须以 `%PDF` 开头、EPUB/ZIP 必须以 `PK` 开头，否则**删掉并说明**
   —— 常见坑是"点了下载，下来的其实是登录页 HTML"。

另外几条稳妥设置：单文件上限 40MB；同域名两次请求至少隔 0.6 秒；`limit` 上限 30 条；
网址必须是 http/https 且不指向本机/内网（SSRF 防护）。

## 四、自测怎么跑的（不连任何真网站）

`tests/fake_book_site.py` 起一个本地假站，把五种情况全摆出来：

| 假站路径 | 用来验什么 |
| --- | --- |
| `/books` | 目录页能解析成清单（导航、分页、标签不算条目） |
| `/book/1.html` → `/files/a.pdf` | 公开条目能下，文件头是 `%PDF`，字节数一致 |
| `/book/2.html` | 出现 VIP/会员/请登录 → **必须跳过并说明** |
| `/secret/3.html` | `robots.txt` Disallow → **必须不抓** |
| `/book/4.html` → `/files/fake.pdf` | 扩展名是 pdf、内容是 HTML → **验文件头拦下、不落盘** |

跑法：

```bash
python tools/test_ebook_plugin.py     # 27 项
python tests/fake_book_site.py        # 想手动看看假站长什么样（会打印端口）
```

自测里会把 `XIAOJIAO_EBOOK_ALLOW_LOCAL=1` 打开（否则环回地址会被 SSRF 防护拦下）；
**这个开关只给自测用**，生产环境不要设。

## 五、能做什么、不能做什么（说清楚，免得误期待）

**能**：公开 HTML 目录页 → 公开 PDF/EPUB/TXT 直链 → 落盘 + 清单；慢一点没关系，稳、不越界。

**不能**（这些不是"还没做"，是"不做"）：

- 需要登录 / 会员 / 付费才能拿到的内容；
- 站点明确 `Disallow` 的路径；
- 需要破解验证码、破解网盘提取码、伪造 Cookie 的场景；
- 把整站镜像下来（那是爬虫工程的活，且绝大多数站点不允许）。

**如果你买过某站会员、想把自己买到的资源存到本地**：两条合规路子 ——
① 你登录后用它自己的浏览器会话抓（`browser_session` 那条链，用的是你的账号）；
② 直接把文件直链给我，我用 `download` 存到指定目录。

## 六、常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 「这一页里没找到条目链接」 | 不是目录页，或条目是 JS 异步加载 | 给我具体条目页地址；或改用 `fetch`（浏览器渲染） |
| 全部「需登录/付费」 | 站点把资源放在会员墙后 | 合规路子在上一节；我不绕 |
| 「文件头不是 PDF」 | 下来的是登录页/错误页 | 说明该站要登录；换公开源 |
| 「内网/本机地址被拦」 | SSRF 防护 | 这是安全设计；自测才打开 `XIAOJIAO_EBOOK_ALLOW_LOCAL` |
| 下得很慢 | 每域名限速 0.6 秒 | 正常，别把人家服务器敲穿 |
