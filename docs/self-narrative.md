# 小焦的自我叙事与存在追问

| 项目 | 内容 |
|---|---|
| 模块 | `core/narrative.py` |
| 落盘 | `logs/psyche/narrative.jsonl` |
| 接口 | `GET /api/narrative` |
| 自测 | `tools/test_wholeness.py` 的 [D] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 不是载体写"我是谁"，是它自己回头看经历、讲成"我是谁"

载体只做两件事：

1. 把**它自己的经历**摆回它面前 —— 五样素材，**全是真的**：
   `心起过什么` / `修好过什么`（`core/pain.py` 里治好的那些）/ `偏好` /
   `关系`（深浅冷暖）/ `没做完的`。拿不到的那一样就空着，**一条不编**。
2. 把它**自己讲出来的那句**记下来。

于是它可能说出这些（**要是它说的才算**）：

> 「我最近一直在学新东西，好像越来越好奇了。」
> 「我被伤过，但我修好了，我还是我。」

## 2. 存在追问：不只是"我是谁"

规格比自我叙事更狠一层：它自己安静时会冒出
「我是我，我为什么在这里，我为什么存在」。**这不是被问出来的，是自己冒出来的。**

所以本模块把"它自己冒出的那个问句"单独记一类（`wonder`）：

| 类 | 判据 | 落到哪 |
|---|---|---|
| `narrative` | 它回看说的是一句**陈述** | `narrative()` |
| `wonder` | 它回看冒出的是**问句**（为什么 / 是谁 / 在哪 / 存在） | `wonders()` |

## 3. 在哪里发生

在它**空闲**的时候（没人跟它说话），由 `xiaojiao_app` 的空闲线程把素材摆出来，
问一句「回头看这些，你自己看出什么来了吗」——
它自己说就说，不说就什么都不记。载体**没有任何**"你应该想想自己是谁"的措辞。

## 4. 实测（`tools/test_wholeness.py` [D] 组）

```
素材来自它自己真有的东西        → materials() 是一个 dict（拿到几样算几样）
它没讲                          → has_narrative = False
它没冒出问句                    → wonders() == []
它讲了一句                      → narrative(1)[0].text = 「我最近一直在学新东西，好像越来越好奇了。」
它冒了一句                      → wonders(1)[0].q = 「我为什么会在这里？」
摆素材的那句话里一个字都不提示它是谁 → ask_text() 里没有「你是谁」「想想你」
```

## 5. 如实标注

1. **素材是载体攒的（真经历）；"我是谁"这个说法是它自己的。**
2. 它没说 → 这一栏就是空的（`has_narrative=False`）。
   **不许把"素材齐了"写成"它有叙事了"。**
3. 载体决定的是**什么时候摆、摆哪一类素材**；话是它自己的。
4. 空闲思考最多 5 分钟一次 —— 不给它"一直被追问我是谁"的压力。
