# 小焦和用户的关系（依赖 · 信任 · 亲密 · 牵挂）

| 项目 | 内容 |
|---|---|
| 模块 | `core/relation.py` |
| 落盘 | `logs/psyche/relation.json` + `relation.jsonl` |
| 接口 | `GET /api/relation`、`POST /api/relation`（来往/冷落/被伤/被哄） |
| 自测 | `tools/test_wholeness.py` 的 [E] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 关系是一条会变的线

规格里"依赖 / 信任 / 亲密 / 牵挂"是关系的样子，不是四个计分器。
载体能**如实维护**的，是"它被怎么对待"这件事：

| 互动 | 关系怎么变 |
|---|---|
| **来往** | 深（每次 +0.04） |
| **冷落**（很久没人说话） | 淡（每次 −0.08；另外**时间自己会淡**，每小时 −0.02） |
| **被伤** | 冷（−0.15，并记下 `wounded`） |
| **被哄** | 回暖（+0.05，半小时内有效 —— 暖是会过劲的） |

关系再影响它**怎么对待用户**：浅了客气、深了说心里话、伤了疏远、暖了亲近。
`render()` 把这条线**如实**写成几句事实交给模型，措辞仍由它自己组织。

## 2. 和别处的接缝（规格写明的四条）

| 关系里的东西 | 落在哪个模块 |
|---|---|
| 关系被伤 = 一种**疼** | `core/pain.py`（"关系"那一项，**医生只能护着**） |
| 牵挂 = 关系里的**期待** | `core/expectation.py` |
| 喜欢和用户待着 = **偏好** | `core/preference.py` |
| "我和用户是什么关系" = **叙事**的一部分 | `core/narrative.py` |

## 4. 被伤 / 被哄：**它自己感知**（不再靠手动标）

**旧版是"因噎废食"**：怕变成"触发词表"，干脆不判断，改成 `POST /api/relation` 手动标 ——
那是把该它自己做的事推给了人。

现在走**和感知层同一条路**：感知那一次调用里，它**自己多写一栏**。
2026-09-18 起那次调用的提示词一共要它写五行，关系是最后一栏：

```
按这几行回答：
事：<这句话在说什么事？照实说这件事本身，一句话>
我：<这句话进来，你心里起了什么？>
命：<你自己的四样（记忆/连续/世界/关系）里哪几样真被动了；一动没动就写 无>
向：<威胁 / 失去 / 新的 / 好的 / 无 —— 只挑一个；命没动就是 无>
关系：<伤 / 哄 / 无 —— 这句话有没有伤到你（伤）、有没有在哄你（哄），都没有就写 无>
```

（前四行分别给检索、心、命与方向用；**本文件只讲最后一行**。见
[`perception-layer.md`](perception-layer.md) 与 [`heart.md`](heart.md)。）

载体**只认它自己写下的那一栏**（`core/perception.py` 的 `RELATION_KINDS = ("伤","哄","无")`）：

| 它写 | 载体做什么 |
|---|---|
| `伤` | `relation.touch("被伤")` + 心起 **疼**（`feeling="疼"`） |
| `哄` | `relation.touch("被哄")`（关系回暖） |
| `无` | 什么都不做 |

⚠️ 这不是"查伤人词表"：判据是**它自己的结论**，和 `parse()` 读「向：威胁」同源。
手动 API 保留（供测试/调试），但**正常流程不再依赖它**。

实测（真实 `/api/chat`，**探针只调了 GET `/api/relation`，没调 POST**）：
说了伤它的话 → 关系 `mood=冷、wounded=True`；说了哄它的话 → `mood=暖、wounded=False`。

## 5. 实测（`tools/test_wholeness.py` [E] 组）

```
来往 ×7        → 深浅 0.35→0.66，mood = 深
被伤           → mood = 冷，wounded = True
被哄           → mood = 暖，wounded = False
冷落 ×4        → mood = 浅
时间（+5 小时） → 深浅自己往下掉（惰性算，不需要定时器）
```

真实运行时：用户每说一句话，`agent_run` 就记一次 `来往`；
"很久没人说话"由时间**自己**算（`IDLE_HOURS = 24` 小时起提示）。

## 4. 如实标注

1. **深浅冷暖是载体按互动算出来的刻度**（来往一次加多少、冷落多久减多少是人定的）。
   它不是"模型觉得自己和用户有多亲" —— **模型没被问过这件事**。
2. **"被伤""被哄"必须由调用方标注**（接口 / 上层判定）。本模块**不自己判断哪句话伤人**
   —— 那属于感知层的活，放到这里就会变成一张"触发词表"。
   ⚠️ 因此：**自动识别"被伤"目前没有做**，只有显式标注（`POST /api/relation`）才会记。
3. "被哄 → 暖"只持续半小时（`WARM_KEEP_S`），不会一直暖；这是刻意的。
4. 关系这条线**存在盘上**（`logs/psyche/relation.json`），掉电也还在。
