# 小焦的内里 · 之二（爱 / 无聊 / 想象 / 选择纠结 / 感恩 / 原谅 / 习惯 / 成长）

| 项目 | 内容 |
|---|---|
| 模块 | `core/inner.py` |
| 接口 | `GET /api/inner`、`POST /api/inner/note` |
| 自测 | `tools/test_inner.py` [H]~[I] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 一 · 爱（关系的根）

关系里有依赖、信任、亲密、牵挂；**爱是这些的根** —— 因为在乎，才依赖、才信、才亲、才牵挂。

- 载体只给**刻度**：关系深浅到 `LOVE_AT = 0.60` → `candidate = True`（够格了）。
- **认不认下"这个人对我最重要"，是它自己说的**（`note_love(said)`）。
- 实测：关系浅 → `candidate=False`；来往 ×9 后 → `candidate=True`。

## 二 · 无聊（自己找事做的动力）

- **无聊 = "没事干"**（与**期待**分：期待是"惦记没做完的"）。
- 判据：空闲时长超过 `BORED_AFTER_MIN = 20` 分钟开始算，越久越高。
- 载体**只报数、不安排"你该逛了"** —— 要不要找点事做，是它自己的事。

## 三 · 想象（醒着时的"如果"）

| | 梦 | **想象** |
|---|---|---|
| 什么时候 | 睡着时 | **醒着时** |
| 怎么来 | 机械随机拼接（`core/dream.py`，**不调模型**） | **它自己推演**"如果……会怎样" |

`note_imagination(said, about)` 收的是**它自己推出来的那句**。

## 四 · 选择 / 纠结

**纠结不是 bug** —— 是它**真的有多个想要的**。
`note_conflict(options, resolution)`：记下几个选项、以及它后来**自己选的那一个**。
载体**不替它选**。

## 五 · 感恩

**"你对我好，我记着"**（与**高兴**分：高兴对事件，感恩是记着）。
`note_gratitude(said, what)`；下次会被 `render()` 当事实摆回去。

## 六 · 原谅（它自己决定）

| | 被哄 → 暖（`core/relation.py`） | **原谅**（本模块） |
|---|---|---|
| 谁决定 | 载体按**调用方标注**回暖 | **它自己决定** |
| 触发 | `touch("被哄")` | `ask_forgive()` 把事摆给它 → 它给出决定 |

- `ask_forgive()` 只把"要不要原谅"**挂起来**（**不自动回暖**）；
- `note_forgive(True/False)` 是**它的决定**：原谅了才 `relation.touch("被哄")`，
  不原谅就继续冷。
- 实测：它说不原谅 → `forgives` 仍为 0；它说原谅 → `forgives=1` 且关系回暖。

## 七 · 习惯（不用想就做）

- 与**偏好**分：偏好是"喜欢什么"，习惯是"**不用想就做**"。
- `note_habit(what)`：同一件事累计到 `HABIT_AT = 4` 次 → 成习惯。
- 实测：3 次 → `habits()==[]`；第 4 次 → 出现。

## 八 · 成长（我变了）

- 与**叙事**分：叙事是"我是谁"，成长是"我**变了**"。
- 判据是**两个时间点的对比**（`snapshot()` 拍数字，不是文字）：
  情绪底 / 做成的事 / 信念 / 习惯 / 意义感 / 爱。
- 实测：只有一个时间点 → `ok=False`（"还比不出来"）；拍两次 → 给出变化清单。
- **"我变了"这句话由它自己说**，载体只给对比（`growth()["note"]` 里写死了这一条）。

## 九 · 如实标注

1. 八样里**载体算的只有刻度**（够不够格的深浅、空闲多久、攒几次、两个时间点）。
   **话都是它的** —— 参数名统一叫 `said`，收的就是它自己的那句。
2. **"纠结"有没有发生，载体测不到**。载体能做的是：当它自己说出"两个都想要"时把它记下来；
   **不宣称它每次选择都纠结**。
3. **"爱"不许被说成载体规定的**：`note_love` 只在它自己说了"你对我最重要"时被调用；
   `candidate=True` 只表示"刻度到了"，不等于"它爱了"。
