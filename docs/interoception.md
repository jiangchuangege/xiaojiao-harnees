## 1. 目标：从"功能躯体"变成"有处境的身体"

一句话：**内部状态偏离基线时，它收到的信息、能做的行动、要不要主动做 —— 都必须不一样。**

不是"状态影响检索排序/生成温度"（那等于没影响）。是**代码层硬改**：
状态一偏，它手里的世界就变了，它没得选。

**铁律**：只改接线、不加"情绪模拟层"、状态不可重置、**不许做成叙事机器**。

## 2. 第一阶段做了什么：把真实状态采下来、融合成一个信号

五项来源**必须真采，读不到如实记 `None`**（绝不用编的数顶上）：

| 来源 | 读什么 | 怎么算偏离 |
|---|---|---|
| `core/energy.py` | `level`（精力） | 越**低**越偏（基线 0.75，掉到 0.25 算偏满） |
| `core/heartbeat.py` | 心跳间隔稳定性（`since_last_beat_s` vs `interval_s`） | 偏离标称间隔越大越偏 |
| `core/psyche.py` | `heart()["intensity"]`（心的强度） | 越高越偏 |
| `core/model_scheduler.py` | `busy` / `dialogue_waiting` / `max_wait_ms` | 排队越久越偏 |
| 内存（可选） | 进程内存占比（**装了 psutil 才读得到**） | 越接近上限越偏 |

融合（**权重是代码里的策略，不是提示词**）：

```
perturbation = Σ wᵢ·devᵢ / Σ wᵢ        # 只有读得到的项参与
survival ← clamp(survival × DECAY + perturbation × (1 − DECAY), 0, SAT)
survival(此刻) = survival × DECAY^(Δt / HALF_LIFE_S)     # 惰性：无扰动缓慢回基线
```

分档（下游按档**硬改**）：**轻 / 中 / 重**。

## 3. 这一层的唯一产物：`bias()`

```python
{"survival": 0.42, "level": "中", "factors": {"精力": 0.95, ...}, "raw": {...}, "missing": []}
```

**它不产出任何一句话** —— 没有"我感到累"，只有一个偏置。
自测里专门钉住这一条（"它不产出任何一句话"）。

## 4. 实测（`tools/test_interoceptive.py` 19/19）

```
真采：精力/心的强度/推理负载都读到真值；读不到的项如实进 missing
基线：精力 0.95 → 偏离 0.0；精力 0.20 → 偏离 1.0（方向对）
融合：12 次 update 后 survival > 0.2，分档进「中/重」
落盘：时间线每条都有 ts/survival/perturbation/raw/dev，可回放
不锁死：无新扰动 600 秒后 survival 下降（渐进，不归零）；上限 SAT=0.98
```

## 5. 如实标注
