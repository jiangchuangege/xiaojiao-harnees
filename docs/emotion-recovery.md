# 小焦的情绪恢复（心起了，会慢慢回落）

| 项目 | 内容 |
|---|---|
| 模块 | `core/psyche.py`（`recovery` / `dilute` / `sleep_reset`） |
| 自测 | `tools/test_wholeness.py` 的 [H] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 三样回落（规格给的）

| 样 | 怎么落 | 代码 |
|---|---|---|
| ① **时间** | 心起了 → 强度自己慢慢降 | `DECAY_PER_SECOND = 0.002`（0.55 起，约 4 分钟回落到 0.3 上下） |
| ② **新事** | 新事来 → 旧心被冲淡 | `dilute(part)`：把强度按比例压下去（**那句话还在**） |
| ③ **睡觉** | 睡一觉 → 情绪重置一部分 | `sleep_reset()`：`SLEEP_RESET_PART = 0.5` |

## 2. 和"心带模型走"不冲突

**先带着走，过一阵才回落** —— 就像人：被吓了先怕一阵，过会儿才慢慢松。

```
心起（强度 0.55）→ 这一轮它就在这个方向里想、检索也偏这个方向
                 → 过一阵，强度自己降
                 → 新事来，再冲淡一次
                 → 睡一觉，重置一半
```

`colors()`（心带模型走）读的是**回落之后**的强度，所以"带着走"是会**渐渐松开**的 ——
不是一直拉满（一直拉满等于没有区分度）。

## 3. 和"疼"的区别

| | 疼 | 情绪恢复 |
|---|---|---|
| 什么时候 | **命被真伤**（记忆脏了 / 连续断了 / 世界没了 / 关系伤了） | 心起了（哪怕没坏） |
| 靠什么 | **找医生**（`core/pain.py`） | **时间 / 新事 / 睡觉** |
| 心里的标记 | `feeling="疼"` | `feeling=""` |

## 4. 实测（`tools/test_wholeness.py` [H] 组）

```
心起                    → intensity=0.55，at 记下来了
过了 100 秒             → 强度降到 0.35（时间那一档）
过了 10000 秒           → 强度 0（放得够久会回落干净）
dilute(0.5)             → 强度减半，**那句话还在**（「心里一紧。」）
sleep_reset()           → 再降一半
```

## 5. 如实标注

1. **回落是载体按时间算的，不是模型"感觉淡了"。** 载体观测不到它的内在状态，也不假装能；
   它只是让"此刻的心"有一个真实的、会变的量。
2. `intensity` 现在是**回落之后的真值**，`intensity0` 才是起时的那个数
   （两个都给了，免得看不出"它起过多强"）。
3. 强度衰减**不代表它忘了这件事** —— 那是记忆层的活（`core/feeling_memory.py`）：
   心落回去了，但"那类事我心起过"的印象还在。
