# 最小权限（读本地文件）

| 项目 | 内容 |
|---|---|
| 模块 | `core/security/minimal_access.py` |
| 红线归属 | 两条安全红线之二（之一是 `no_delete` 不删文件） |
| 自测 | `tools/test_4_gaps.py` 第 [5] 组 |
| 文档状态 | 已发布，内容与代码同步 |

## 1. 摘要

小焦的"世界"是**互联网**，不是本地磁盘。主动逛世界时它只逛网上，完全不碰本地。

只有当**用户明确指定了一个文件**时，它才去读那**一个**。

> 这是**权限边界**，不是体验优化。去掉它，模型只要说一句"读一下配置文件"，
> 就能把磁盘上任意文件的内容带进对话。

---

## 2. 七条判据，逐条对应一个真实的坏习惯

| # | 判据 | 对应的坏习惯 |
|---|---|---|
| ① | **只读这一个** | 顺手把同目录扫一遍 |
| ② | **不推测、不扩展** | 路径不完整（"那个文档"）时自己猜一个 |
| ③ | **读完即弃** | 把内容留个副本 / 写进落盘文件 |
| ④ | **不混进世界记忆** | 本地内容进了世界模型，下次"逛世界"带着磁盘内容上路 |
| ⑤ | **权限不足如实说** | 换路径、提权、绕路 |
| ⑥ | **凭据类先警告** | `.ssh` / `.env` / `id_rsa` 直接读，不由用户决定 |
| ⑦ | **必须是真实存在的文件** | 目录、通配符、不存在的路径也照读 |

**判据②的理由最要紧**：猜错的代价不是"读错文件"，而是"**读了不该看的文件**"，
这个方向没有回头路。所以路径不明确时**问用户**，绝不猜。

---

## 3. 实测行为

`tools/test_4_gaps.py` 第 [5] 组（全部通过）：

| 场景 | 结果 | 说明 |
|---|---|---|
| 用户明确指定、文件存在 | **读到** | 正常路径 |
| 用户**没**明确指定 | 拒绝 | "用户没有明确指定这个路径，载体不主动读本地文件" |
| 路径含 `*` / `..` | 拒绝 | "路径里有通配符或上跳 —— 载体不展开、不推测范围" |
| 路径是目录 | 拒绝 | "这是一个目录，不是文件 —— 载体不代你遍历目录" |
| 路径不存在 | 拒绝 | 如实报出那个不存在的路径 |
| 空路径 | 拒绝 + `need_ask=True` | 应当回去**问用户**，而不是猜 |
| `.ssh/id_rsa` 这类 | 识别为凭据 | `is_credential()` 命中即警告，**要用户确认**才读 |

## 4. 接口

| 函数 | 签名 | 说明 |
|---|---|---|
| `check_path` | `check_path(path, explicit=False)` | **只检查不读**，返回 `{"ok","path","reason","need_ask","warning"}` |
| `read_once` | `read_once(path, explicit=False, confirmed=False, max_bytes=MAX_READ_BYTES)` | 读一个文件，用完即弃 |
| `is_credential` | `is_credential(path)` | 这个路径像不像凭据文件 |
| `MAX_READ_BYTES` | `256 * 1024` | 单次读取上限 |
| `CREDENTIAL_HINTS` | — | 凭据类文件名/目录特征表 |

两个关键参数：

- `explicit=True` 表示"**用户明确指定了路径**"。不传就是拒绝 —— 载体不主动读本地文件。
- `confirmed=True` 表示"**用户已经确认**要读凭据类文件"。不传就是拒绝并给出警告文案。

`read_once` 的返回值**始终带 `need_ask`**：调用方据此决定"该不该回去问用户"，
而不是只看 `reason` 字符串去猜。

**超出上限时截断并如实告知**（`truncated=True` + 说明截到多少字节），不静默丢内容。

## 5. 与另一条红线的关系

| 红线 | 模块 | 挡住什么 |
|---|---|---|
| 一：不删文件 | `core/security/no_delete.py` | 一切删除/清空/重置类操作 |
| 二：不越权读文件 | `core/security/minimal_access.py`（本文档） | 读用户没有明确指定的本地文件 |

两条都由**代码层硬拦**，不依赖提示词里写"请不要"。

---

## 6. 边界与限制

- **"用户明确指定"是由调用方声明的**（`explicit=True`）。本模块**无法自行判断**这个标志是不是真的来自用户 —— 它只能保证"声明了才放行"。上游如果把模型自己生成的路径当成用户指定，那这道门就形同虚设。
- **凭据识别是文件名匹配**，不是内容扫描。**改过名的凭据文件**（比如一个名字很普通的文本文件里放着私钥）识别不出来。
- **没有沙箱**：读到的内容会进入对话上下文，可能被模型复述。"读完即弃"保证的是不落盘、不进记忆，不保证不进上下文。
- **`max_bytes` 是字符数不是字节数**（按 UTF-8 文本读）。超大二进制文件会被 `errors="replace"` 读出一堆替换字符，建议先确认文件是文本。
- **不判断内容敏感性**。它管的是"能不能读这个路径"，不管"读到的内容该不该出现在回答里"。
