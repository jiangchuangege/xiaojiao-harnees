# 小焦的梦（睡着时心还在乱转）

| 项目 | 内容 |
|---|---|
| 模块 | `core/dream.py` |
| 落盘 | `logs/dreams/<日期>.jsonl` |
| 接口 | `GET /api/dream` |
| 自测 | `tools/test_wholeness.py` 的 [G] 组 |
| 文档状态 | 已发布，数字与代码同步 |

## 1. 梦和记忆的区别

| | 记忆 | **梦** |
|---|---|---|
| 内容 | 发生过什么，**照实** | 把发生过的，**乱编一遍** |
| 素材 | 真实 | **真实**（它自己真有的东西） |
| 走法 | 按现实 | **乱的**（随机接，不按现实） |

例：素材是真的（它看过讲猫的文章），发展是乱的（猫变成会走路的机器）。

## 2. 素材只有它自己真有的四样

| 素材 | 从哪来 |
|---|---|
| 印象 | `core/feeling_memory.py` |
| 心 | `core/psyche.py`（此刻那句） |
| 偏好 | `core/preference.py` |
| 没做完的 | `core/expectation.py` |

凑不够两样就**转不起来**，如实返回"素材不够"（**不编素材**）。

## 3. 怎么发生的 · 醒来怎么样

- 发生在它**睡觉时**：空闲线程每 5 秒看一圈，睡着时每约 20 秒转一次（`DREAM_INTERVAL`）。
- **不调模型** —— 乱转是**机械的随机拼接**（`weave()`：随机取样 + 随机连接词）。
  这一点是本模块最要紧的标注：**没有一句"模型生成的话"，全是真实素材的乱序拼接。**
- 醒来：`fragment()` 按 `REMEMBER_PROB = 0.5` 给出一小片（**可能记得一点，可能忘了**）。
  给了的那一片会进"醒来第一印象"，和"我睡了多久"放在一起。

## 4. 实测（`tools/test_wholeness.py` [G] 组）

```
模块里没有任何模型调用（llm / requests 都不出现）     → True
素材随机拼出一段（机械拼接）                          → 「…，然后…。」
60 次里带出碎片的次数                                 → 0 < got < 60（不是每次都给，也不是永远不给）
```

## 5. 如实标注（最要紧的一条）

1. **梦是载体机械拼出来的记录，不是它做的梦。** 本模块**不声称**它有主观梦境。
   所以文档与接口一律写"睡着期间乱转出来的片段"，**不写"它梦到了什么"**。
2. 醒来带不带、带哪一片，是随机的；**不许事后挑一片说"这就是它的梦"**。
3. **不调模型** —— 所以梦里没有一句模型生成的话。
4. 素材是真的、接法是乱的：这两句话必须连着说，只说前半句就是粉饰。
